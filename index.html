How the hybrid policy works

  1. Try the device first. Firefox AI Logic asks Chrome for a Gemini Nano session (PREFER_ON_DEVICE). If the model is present, the text never leaves the machine and costs nothing.
  2. Fall back, don't fail. No model, no download, or a document larger than the 9,216-token on-device window → the same call is served by Gemini in the cloud.
  3. Say which one happened. Every response carries inferenceSource; the badge above is read straight from it, never guessed.

Chunk size and the default policy come from Firebase Remote Config, so the trade-off can be tuned without shipping a new build.

    How Hybrid Scribe works
    
          
    
            A research assistant for students and field researchers who work with long documents in
            places with bad Wi-Fi. It runs on the device when it can, and quietly borrows the cloud
            when it can't — and always tells you which one answered.
          
    

          
    The problem
    
          
    
            Field notes, transcripts and PDFs are long, personal and often handled offline. Cloud-only
            assistants upload everything and stop working in a basement or a nature reserve. On-device
            assistants are private and free, but the model is only on some machines and has a small
            context window. Neither alone is a reliable tool.
          
    

          
    The hybrid loop
    
          
    document ──▶ chunk (Remote Config size) ──▶ ┌───────────────┐
                                          │ AI Logic      │
                                          │ PREFER_ON_     │──▶ Gemini Nano (device)
                                          │ DEVICE         │        │ no model /
                                          └───────────────┘        │ too long
                                                    ▲                ▼
                                                    └──── Gemini (cloud fallback)
                                          response.inferenceSource → badge + latency
    

          
    What each Firebase product does
    
          
      
            
    • AI Logic (hybrid inference) — one GenerativeModel per mode,
              generateContent() for each chunk, a reduce pass over the chunk summaries, and a
              question pass grounded in the most relevant chunks.
      • 
            
    • App Check — attestation in front of the Gemini API. The live demo uses a
              registered debug token (allowed by the hackathon rules); a production build would swap in
              Fraud Defense / reCAPTCHA.
      • 
            
    • Authentication — anonymous sessions, so a visitor gets a private
              Firestore namespace without creating an account.
      • 
            
    • Cloud Firestore — saved documents and answers, scoped to
              users/{uid}/notes by security rules.
      • 
            
    • Remote Config — chunk_size, max_chunks,
              hybrid_policy and qa_context_chars, fetched at start-up, so the
              cost/latency trade-off is tunable without a deploy.
      • 
            
    • Hosting — the static Vite build.
      • 
          
    

          
    Where the device model exists
    
          
    
            Gemini Nano ships with Chrome on Windows, macOS and ChromeOS (desktop,
            version 139+), behind chrome://flags/#prompt-api-for-gemini-nano-multimodal-input.
            Linux builds of Chrome/Chromium do not include the model service, so demo runs there always
            answer in cloud — the fallback is the feature, not a bug.
          
    

          
    Limits we designed around
    
          
      
            
    • On-device inference is single-turn text only: no chat history, no tools, ~9,216 tokens.
      • 
            
    • JPEG/PNG are the only on-device image inputs; this app stays text-first.
      • 
            
    • countTokens() is unreliable across paths, so chunking is character-based.
      • 
            
    • Console AI monitoring only sees cloud inference; the UI is the source of truth for path.
      • 
          
    

          
    Privacy model
    
          
    
            Documents are stored in Firestore only when you press Save, under your anonymous uid,
            and are deletable from the list. When a request is served on-device, the document text is not
            sent to Google; when it is served in the cloud, it is sent to the Gemini API under the
            project's quota.
